# Food Website Layout

A clean, responsive, and minimal 4-page Food Restaurant website featuring Home, Menu, About Us, and Contact Us sections. Built using semantic HTML5 and clean CSS3 layouting.

📌 Features

* Clean UI: Simple, attractive layout designed specifically for a restaurant brand.
* Multi-Page Architecture: Structured across 4 distinct pages (`index.html`, `menu.html`, `about.html`, `contact.html`).
* Menu Grid: Itemized food section showcasing images, pricing, and short descriptions.
* Flexbox Alignment: Perfectly centered layout and card containers using standard CSS flexbox.
* Human-Coded Style: Straightforward, readable HTML/CSS structure without unnecessary code complexity.

🛠️ Tech Stack

* HTML5
* CSS3
